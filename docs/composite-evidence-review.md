# Evidence review for composite reports

Free-form composite reports now pass through the same native factual-consistency
review and bounded narrative repair as evaluation and comparison reports.
Previously, the composite synthesis path could return a structurally valid report
without checking its claims against the completed scientific tasks.

The reviewer receives the complete source and an index of exact source pointers.
That index now includes each evaluation's targets, reference context and recorded
splice summary. Separate tasks can evaluate the same physical molecule against
different targets. Their scores and skipped statuses remain separate observations;
an unrecorded result at one target cannot be supplied by a calculation at another.
Zero-valued calculations are retained as recorded values.

Findings must quote an actual draft field and cite existing source paths. Repair
may change only flagged narrative fields; computed results and unflagged narrative
remain unchanged. A corrected draft is reviewed again. An unavailable or invalid
review cannot be accepted as an unchecked report. The existing conservative
narrative fallback remains available when repeated repairs fail.

Deterministic reports continue to render their source-backed results directly.
This change covers the free-form composite fallback and adds native model work
when that path is used. Its review receipt means no factual inconsistency was
flagged in that pass, not independent scientific validation or a benchmark grade.
The actual effect on task correctness, cost and latency must be measured in fresh
executions after the candidate is frozen.
